# 🌦️ AI Weather Agent

Streamlit web app with current weather, 8-day forecast, specific date search, hourly weather, date-range search, 10-minute live refresh, Gemini analysis, and Gemini weather chat.

## Streamlit Secrets

Add:

```toml
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
```

Never commit the API key to GitHub.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
